## Recursos Esenciales para Desarrolladores 🚀

Una colección curada de enlaces y herramientas para agilizar tu flujo de trabajo de desarrollo.

---

### 🤖 UI con IA

Herramientas que utilizan inteligencia artificial para generar componentes, prototipos y estilos de interfaz de usuario.

| Sitio Web           | Descripción                                                                                           | Enlace                                                           |
| :------------------ | :---------------------------------------------------------------------------------------------------- | :--------------------------------------------------------------- |
| **v0 by Vercel**    | Genera interfaces de usuario responsivas a partir de un prompt, utilizando Shadcn UI y Tailwind CSS.  | [https://v0.dev/](https://v0.dev/)                               |
| **Lovable**         | Plataforma de desarrollo con IA que ayuda a construir, diseñar y lanzar aplicaciones web rápidamente. | [https://lovable.dev/](https://lovable.dev/)                     |
| **Bolt**            | Generador que crea un sistema de diseño (colores, fuentes, componentes) con un solo clic.             | [https://bolt.new/](https://bolt.new/)                           |
| **Stitch (Google)** | Herramienta experimental de IA (en beta) para ayudar a crear prototipos de ideas de productos.        | [https://stitch.withgoogle.com/](https://stitch.withgoogle.com/) |

### 🖼️ Imágenes y Placeholders

Herramientas para obtener imágenes de relleno, avatares y contenido visual para tus maquetas y proyectos.

| Sitio Web         | Descripción                                                                 | Enlace                                                 |
| :---------------- | :-------------------------------------------------------------------------- | :----------------------------------------------------- |
| **Unsplash**      | Banco de imágenes de alta resolución, libres de derechos y de uso gratuito. | [https://unsplash.com/](https://unsplash.com/)         |
| **Pexels**        | Otra excelente fuente de fotos y videos de stock gratuitos.                 | [https://www.pexels.com/](https://www.pexels.com/)     |
| **picsum.photos** | Generador de imágenes de relleno (placeholder) con URLs fáciles de usar.    | [https://picsum.photos/](https://picsum.photos/)       |
| **placehold.co**  | Crea imágenes de placeholder personalizadas con dimensiones y texto.        | [https://placehold.co/](https://placehold.co/)         |
| **DiceBear**      | Generador de avatares SVG únicos y personalizables para tus usuarios.       | [https://www.dicebear.com/](https://www.dicebear.com/) |

### 📊 Datos Falsos (Fake Data)

Generadores de datos de prueba para poblar tus aplicaciones y bases de datos durante el desarrollo.

| Sitio Web           | Descripción                                                                                              | Enlace                                                                         |
| :------------------ | :------------------------------------------------------------------------------------------------------- | :----------------------------------------------------------------------------- |
| **JSONPlaceholder** | Una API REST falsa y gratuita, ideal para prototipado y tutoriales.                                      | [https://jsonplaceholder.typicode.com/](https://jsonplaceholder.typicode.com/) |
| **Mockaroo**        | Permite generar grandes cantidades de datos ficticios en formatos como CSV, JSON y SQL.                  | [https://www.mockaroo.com/](https://www.mockaroo.com/)                         |
| **Faker.js**        | Librería para generar datos masivos falsos en el navegador y Node.js (ahora mantenida por la comunidad). | [https://fakerjs.dev/](https://fakerjs.dev/)                                   |
| **Random User Gen** | API que genera perfiles de usuario aleatorios con fotos, nombres y más.                                  | [https://randomuser.me/](https://randomuser.me/)                               |
